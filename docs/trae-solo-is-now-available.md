# TRAE Work — Important Updates

> Snapshot of the official announcement page from TRAE docs.
> Source: <https://docs.trae.ai/ide/trae-solo-is-now-available?_lang=en>

## Summary

**TRAE Work standalone clients are now available.** TRAE Work is an AI-native
workspace that offers **web, desktop, and mobile** clients. It features two
modes — **Work** and **Code** — designed for different user groups.

TRAE Work builds upon TRAE IDE's **SOLO mode** with further enhanced
capabilities, aiming to provide users with a unified, efficient, and
customizable AI collaboration experience that covers scenarios ranging from
professional development to everyday office work.

## Key Concepts

- **TRAE Work** — new AI-native workspace product, successor of TRAE IDE's SOLO mode
- **Two modes**: Work (office/productivity) and Code (development)
- **Clients available**: Web, Desktop, Mobile
- **Inheritance**: extends TRAE IDE's SOLO mode capabilities
- **Scope**: from professional development to everyday office work
